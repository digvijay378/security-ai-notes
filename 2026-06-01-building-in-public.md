# 2026-06-01 — Why I'm building security tools in public

For years most of my work lived behind client NDAs. That's changing.

I'm starting to extract the useful patterns and tools from real engagements and open source the non-sensitive parts.

Benefits I've noticed already:
- Forces me to write cleaner code and better docs
- Gets feedback from other practitioners
- Creates a public body of work that actually demonstrates skill

The green squares are a side effect. The real goal is shipping things that are useful to other security engineers.
